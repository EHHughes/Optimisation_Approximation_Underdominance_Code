**Coarse_Graining_IBMS**

Code for the coarse-graining project: fitting surrogate models to the individual-based mosquito model and optimising gene-drive release strategies.

**Directory layout**

```
Coarse_Graining_IBMS/
├── src/     # all source code — see src/README.md
├── tests/   # pytest suite
├── hpc/     # Apptainer recipe and Slurm script for the optimisation runs
└── data/    # input data, generated data, trained models, and figures
```

See the repository root README for provenance and for how to install and run this code.
