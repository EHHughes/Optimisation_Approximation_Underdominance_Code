## IBM_Emulation

Feedforward neural-network surrogates that emulate the IBM (agent-based model), trained on input-output pair datasets generated by the IBM.

### Homozygote-only (WW/GG) surrogates

Underdominance architectures make the heterozygote non-viable, so the dynamics never visit a state with WG adults. Passing `homozygotes_only=True` (the `--homozygotes-only` flag, shared by `generate_training_data.py`, `train_approximations.py` and `validate_approximations.py`) samples the input adults on the WW/GG face only and fits a genuine two-genotype `(WW, GG) -> (WW, GG)` surrogate to that data, instead of spending most trials on a region the model will never be asked about.

Downstream code is built on a three-genotype `(3,) -> (3,)` / `(N, 3) -> (N, 3)` contract, so `load_pretrained_neural_net` returns the 2-in/2-out net wrapped in `HomozygoteSurrogate`: it drops the WG column going in and re-inserts a zero one coming out. Nothing downstream changes. The MAF is returned unwrapped, because `flow(x)` exposes several APIs; use `make_maf_sampler` for the three-genotype map.

`WG = 0` is an assertion about the architecture, not a measurement: every WW x GG cross still lays heterozygote eggs, and they reach adulthood unless the drive's `wg_*` penalties starve them. `report_heterozygote_residual` measures the output mass that assertion discards and warns above 1%; the trainers call it automatically. Data and models carry a `_homozygotes=True` filename marker, so they can never be confused with the three-genotype ones.

### Files

- **`dataloaders.py`** — PyTorch `Dataset` and `DataLoader` wrappers for the IBM input-output pair CSV files.
  - `InputOutputDataset`: normalises inputs and outputs by their respective maxima.
  - `get_test_train_datasets`: loads separate train/test CSV files by seed and returns `(train_dataset, test_dataset, scalings)`.
  - `get_test_train_dataloaders`: loads a single CSV, randomly splits it into train/test sets, and returns `(train_dataloader, test_dataloader, scalings)`.
  - `select_homozygotes` / `embed_homozygotes`: the `(..., 3)` ↔ `(..., 2)` column pair backing the homozygote-only mode; works on numpy arrays and torch tensors.
  - `report_heterozygote_residual` / `report_heterozygote_residual_for_dataset`: measure the WG share of a dataset's output adults, i.e. what a homozygote-only surrogate discards.
  - `warn_if_heterozygote_inputs_present`: flags the separate mistake of dropping a WG *input* column the data actually varies.
- **`surrogates.py`** — Neural network definition and training utilities.
  - `SimpleFeedforwardNN`: configurable feedforward network (`input_size → hidden_size → 2×hidden_size → … → output_size`) with ReLU activations and a variable number of hidden layers.
  - `construct_surrogate_function`: trains a fixed-architecture network for 900 epochs and saves the weights to disk.
  - `train_loop` / `test_loop`: epoch-level train/eval loops used by `construct_surrogate_function`.
  - `plot_test_set_predictions`: scatter plots of actual vs. predicted outputs per genotype.
  - `load_pretrained_neural_net`: loads a saved model from disk for inference on a different device; with `homozygotes_only=True` returns it wrapped so the three-genotype contract still holds.
  - `HomozygoteSurrogate`: presents a two-genotype (WW, GG) net as the pipeline's three-genotype map, reporting `WG = 0`.

- **`variational_approximations.py`** — Masked Autoregressive Flow (MAF / NSF) as a stochastic alternative to the deterministic feedforward NN; captures the IBM's output distribution rather than just its mean.
  - `train_maf`: trains a normalising flow on the IBM dataset with GPU support.
  - `batch_loop`: single training or evaluation epoch for a zuko flow.
  - `load_pretrained_maf` / `get_maf_mean_prediction`: load a saved flow and compute its mean prediction for inference.
  - `make_maf_sampler`: the one-draw-per-call `(N, 3) -> (N, 3)` adapter the simulation callers need, shared rather than redefined at each call site.
- **`plot_surrogate_model_comparisons.py`** — standalone plotting functions for visualising surrogate accuracy against stochastic IBM runs.
  - `compare_ibm_to_neural_net`: overlays the (deterministic) NN prediction on multiple IBM replicates from the same fixed adult population, illustrating how well the surrogate captures the IBM's central tendency relative to its stochastic spread; supports single-step and multi-step (chained NN) modes.
  - `compare_multigeneration_ibm_to_nn`: multi-generation version of the above comparison.

### Trained Neural Nets

- `surrogate_model_genetics=True.pt` — pre-trained network for the genetics-aware (3-input, 3-output) IBM.
- `..._homozygotes=True.pt` — two-genotype (2-input, 2-output) WW/GG surrogates, for architectures whose heterozygote is non-viable.

### Tests

`tests/test_surrogates.py` covers:

- **`TestSimpleFeedforwardNN`** — architecture shape, hidden-layer depth, width doubling, gradient flow, and batch independence.
- **`TestTrainAndTestLoops`** — verifies `train_loop` reduces loss and `test_loop` returns a non-negative float.

`tests/IBM_Emulation/test_homozygote_only_surrogates.py` covers the homozygote-only mode: the select/embed column pair, `HomozygoteSurrogate`'s contract, the residual diagnostics, and `_homozygotes=True` marker propagation through every filename layer.
